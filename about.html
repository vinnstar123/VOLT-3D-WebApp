About VOLT

VOLT is an interactive 3D web application showcasing three branded energy drink products in 3D in real time, built for a coursework assignment for Web 3D Applications (H7006).
The VOLT 3D App lets users explore three conceptual products: VOLT Original (can), VOLT Sugar Free (can), and VOLT Original Bottled (bottle). Users can explore these products in an interactive 3D viewer and switch between the three products. Each model can be opened with a button click, rotated with the mouse, viewed as a wireframe, and toggle between different lighting moods. Sound effects accompany the opening animations.

Technologies Used

The application is built to work on varying screen sizes using the following tools:

  • HTML5 & CSS3 for page content and styling, with a custom CSS script over Bootstrap.
  • Bootstrap 5.3.8 for the responsive grid, navbar, dropdown, and card components.
  • Three.js r106 for 3D rendering, with OrbitControls for camera navigation, GLTFLoader for loading models, and AnimationMixer for playing keyframed animations.
  • Blender 4.5.4 for modelling, texturing, and animating all three 3D models.
  • JavaScript for all user interactivity: button handlers, model switching, lighting changes, and sound effects.
  • Google Fonts: Orbitron for headings, Stack Sans Notch for body, and Font Awesome for footer icons.

Interactive Features

The 3D viewer page includes the following interactive features:

  • Animation playback: clicking the Open 'Product' button triggers the Blender animation through Three.js.
  • Wireframe toggle: goes through the loaded model's mesh and flips each material's wireframe property.
  • Rotation toggle: a continuous rotation applied inside the render loop in javascript (a second form of animation, distinct from the Blender clip for opening).
  • Model gallery: cycles through all three models, with the labels updating appropriately.
  • Lighting control: switches between bright studio lighting and a dim product reveal mood.
  • Sound Effects: AudioListener attached to the camera plays the appropriate sound effect synchronised with each model's opening animation.

Design Choices

The VOLT brand uses an electric blue (#0033A0) and a lightning yellow (#FFD700) palette, paired with Orbitron which is a futuristic and geometric font to reinforce the energy drink theme. The lightning bolt logo appears throughout the application. The blue and grey pattern on the can evokes motorsport liveries, reinforcing the brand's high-performance and high-octane aesthetic.

Reflection

The most challenging part of this project was integrating the .glb 3D files exported from Blender into the Three.js scene and displaying the animation clips, particularly when implementing the model-switching gallery since each new model requires its own AnimationMixer instance and a clean removal of the previous model from the scene to avoid memory leaks. Combining the JavaScript-driven rotation with the Blender animation required care to ensure both could run simultaneously without interfering.
